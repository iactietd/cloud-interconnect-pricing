## 上云互联专线是什么？和"国际专线"到底有什么不同

"上云互联"对应的英文是 IX / IXP（Internet Exchange Point），本质是不同网络在同一物理交换中心对等互连。在跨境出海的场景里，它的产品形态可以理解成"前置云厂入口 + IXP 网络 + 目标区域 BGP 出口"。

具体路径：你在阿里云 / 腾讯云 / 华为云 / UCloud 等公有云租用一台入口机器，流量先进这台机器的 VPC，再通过 IX 上的 BGP 出口把数据送往目标区域。整个路径不经过北上广传统出口局——这也是它延迟低、价格便宜的根本原因。

相对云厂自家的高速通道（如阿里云 CEN、华为云 DC、腾讯云专线接入），上云互联差异主要有三点：

- **不过传统出口局**：路径短，深港线端内延迟可以低到 1~2ms。
- **价格门槛低**：大厂 2Mbps 端口动辄上千元起步，IX 类专线月付两三百元就能起步。
- **国内段必须自行准备**：你看不到"全程价格"，总成本 = IX 专线费 + 云前置费。

这也是为什么商家报价跨度大：单写 288 元的入口套餐，前置用阿里云轻量又需要额外几十元；只写 166 元的沪日共享，前置没到位又连不通。

## 看"上云互联专线价格"时，决定成本的 5 个变量

MKCloud 在其知识库（文章 42）里写得比较坦诚：跨境专线的费用要连同线路方向、计费方式、服务器配置及接入成本一起比较，不能只比 Mbps。具体看下来，影响报价的因素主要是以下几条：

1. **出口方向**：深港、沪港、沪日、沪美——物理距离差得远，价格跨度也大。深港最便宜，沪美最贵。
2. **共享 vs 独享带宽**：共享是峰值速率，遭遇拥堵时实际速率会下降；独享按 Mbps 持续计费，但起步月费更高。
3. **计费方式**：按月流量（计量型）和按 Mbps（独享带宽型）两类。计量型超量后**暂停服务**，不会自动按高价计费。
4. **流量配额**：从 100GB 到 50TB 不等。MKCloud 6TB 以上才有 1Gbps 峰值带宽，小流量套餐峰值速率会被限制。
5. **云前置成本**：IX 专线只解决跨境段，国内段仍要云厂网络。深港 IX 通常搭阿里云 / 腾讯云 / 百度云华南；沪日 / 沪美更适合阿里云 / UCloud / 华为云华东。

把这 5 个变量拆开列，能让你对比各家报价时不被"低门槛"误导。

## 常见问题（FAQ）

**Q1：上云互联专线能退款吗？**
按 MKCloud 服务条款，仅质量问题支持退款，需在工单中提交测试截图和具体问题，不支持开通后更换地域。

**Q2：流量超量后会怎样？**
计量型套餐按上行 + 下行双向计算。达到限额后**暂停服务**，不会自动按高价计费，可自助购买流量重置或工单补差价升级。

**Q3：能直接跑在大厂账号业务上吗？**
可以，但前置必须用对应云厂的 BGP 网络。当前规则明确：深圳入口支持阿里云 / 腾讯云 / 百度云国内全网，以及火山云 / 华为云华南；上海入口支持阿里云 / 腾讯云 / 百度云国内全网，以及火山云 / 华为云 / UCloud 华东。

**Q4：优惠码可以叠加吗？**
不可以。每个订单只能使用一个优惠码，MK-8.8（流量计费）和 MK-7.8（独享带宽）分别用于不同计费类型，结算页会显示哪一种可应用。

**Q5：为什么 6TB 以上才有 1Gbps？**
带宽与流量配比的常规设计：流量越大，瞬时可用速率越高。3TB / 500Mbps 是 MKCloud 上云互联优化专线目前的性价比甜点，1TB / 200Mbps 起步套餐适合先跑通再扩量。
